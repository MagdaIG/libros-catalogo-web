# libros catalogo web

Aplicación web para explorar libros por título, autor o género usando HTML, CSS, JavaScript y Bootstrap. Incluye búsqueda dinámica, vista de detalles de libros, diseño responsive y uso de formularios. Proyecto desarrollado como parte del Bootcamp de JavaScript.

## Tech Stack

JavaScript (ES6+), HTML5 and CSS3

## Getting Started

```bash
git clone https://github.com/MagdaIG/libros-catalogo-web.git
cd libros-catalogo-web
Open index.html in your browser
```
